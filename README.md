# MySite - Portfolio Personal

Bienvenido a mi portafolio personal. Este sitio muestra mis habilidades, experiencia y proyectos como ingeniero de datos y arquitecto de soluciones en la nube.

## Tecnologías Utilizadas
- **HTML5 & CSS3** - Estructura y estilos con variables CSS personalizadas
- **JavaScript** - Interactividad, efectos de partículas, animaciones y manejo de formularios
- **Responsive Design** - Adaptado para dispositivos móviles y pantallas grandes
- **Git** - Control de versiones

## Secciones Principales
- **Hero** con efecto de typing y partículas en canvas
- **Sobre Mí** con tarjetas destacadas
- **Habilidades** organizadas en categorías
- **Experiencia** cronológica con logros
- **Educación y Certificaciones**
- **Idiomas**
- **Contacto** mediante formulario que abre cliente de correo
